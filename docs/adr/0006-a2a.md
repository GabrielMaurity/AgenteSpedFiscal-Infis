# ADR-0006: Protocolo A2A

**Status**: Aceito
**Data**: 2026-11-05

## Contexto

A constitution (P-20) exige expor o agente por A2A com as mesmas garantias da API REST.

## Decisão

Usar o SDK .NET do A2A (`A2A` e `A2A.AspNetCore`), com Agent Card em `/.well-known/agent-card.json` e
as skills `validar-efd-icms-ipi` e `consultar-efd-icms-ipi`, chamando os mesmos casos de uso da REST.

## Alternativas consideradas

- **Implementar o protocolo manualmente**: maior risco de incompatibilidade.

## Consequências

- **Risco**: o SDK não tem versão estável. Em 2026-11-05, a mais recente é `1.0.0-preview4`, fixada em
  `Directory.Packages.props`. A API pode mudar, então o handler A2A deve ficar fino, restrito aos
  endpoints, e os testes de contrato devem cobrir o Agent Card.
- Migrar para a versão estável quando ela for publicada.
